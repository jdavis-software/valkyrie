## Synchronization rule

Canonical requirements and task status live in the repository task cards. GitHub checkboxes summarize them. When completing a task, update the task status, append real evidence to the execution log, and update the corresponding issue checkbox. Do not close an epic before all required task gates pass. A connector outage is a synchronization blocker, not permission to fabricate a remote update.

Tasks may depend on specific tasks from an otherwise incomplete epic. Follow the actual dependency graph rather than unnecessarily serializing all epics. Optional ideas remain in [Future scope](../FUTURE.md), not hidden checklist additions.
